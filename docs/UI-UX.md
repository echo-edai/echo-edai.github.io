# 门户设计规范

更新日期：2026-11-03。范围为首页、门户导航、文章和四份交互教材的共同界面。

## 设计依据

使用 `ui-ux-pro-max` 检索开发者文档、阅读排版、触控目标与焦点遮挡。
匹配到 Developer Tool / IDE、Dark Mode (OLED) 及文档入口模式；采用高对比、清楚层级和轻量动效，保留现有森林色与荧光绿品牌。

首轮检索误匹配到政务门户配色，已弃用；确认匹配后才确定本规范。字体沿用系统中文无衬线与等宽字体。

## 统一规则

- 正文 16px，行高 1.8～1.9；长文控制在约 76ch，图表与源码工具独立铺开。
- 门户导航 14px，章节目录 13px；装饰性英文标签不承载必要信息。
- 手机主要按钮和目录箭头至少 44×44 CSS px，保持可见焦点与明确选中状态。
- 工作区导航固定，教材索引单独滚动；保留全局折叠、移动抽屉和章节深链接。
- 搜索具有可见标签，筛选结果可读；返回页面恢复关键词和分类。
- 动效只作用于透明度、颜色与位移，遵循系统减少动态效果设置。
- 颜色集中在 `assets/theme.css` 的语义令牌中，正文与背景目标对比度不低于 4.5:1。
- 参考资料保持只读，导入教材内容与原始图像保留；只调整展示层。

## 验证范围

已在真实浏览器检查 1440×960、375×812 和 812×375 三种视口：首页、文章和四份教材均未出现整页横向溢出。手机抽屉、Escape 关闭、全局折叠、教材分组、章节列表与文章目录可展开和收起。

搜索空状态、分类与关键词组合、浏览器返回恢复筛选通过；Gemmini 章节定位后位于工具栏下方，正文为 16px / 1.9。源码弹窗、架构视图切换和 Coral 教材内搜索通过抽查。四份教材分别加载 25、28、21、22 章，并显示就绪状态。本次没有逐一重跑全部教学模型。

语义颜色的静态对比度计算：正文/页面背景约 16:1，次要正文/表面背景高于 8:1，柔和文本/表面背景高于 6:1，强调按钮文本/背景高于 13:1。减少动态效果由媒体查询和原有动画开关支持，本次未切换操作系统设置。

构建检查全部本地链接与章节锚点；Prettier、Ruff 和浏览器脚本语法检查通过。运行产物与截图位于 `work/`。
